Forecast GTA VI's launch-day Twitch viewers hour by hour. The model fits the release-day shape from past big launches' hourly curves in the case file: per-hour log-ratios to the hour-1 print, regressed on log hour-1 size and the unlock type (rolling midnight vs simultaneous), with honest quantiles from the residuals. Python 3.13, standard library only.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
